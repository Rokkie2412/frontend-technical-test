This [Next.js](https://nextjs.org) Project is for Technical Test purpose. Bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).


## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Feature

This Project contain [TMDB](https://developer.themoviedb.org/docs/getting-started) API for get movies data.
This project can search movies by search bar, view detail about selected movie, and can filter movies by available categories.
